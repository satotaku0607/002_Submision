# 恋の既読チャレンジ 💌

LINE風のトーク画面で「ひろ君」にメッセージを送り、返事のゆくえを楽しむ恋愛ゲームです。
送ったメッセージによって、即レス・スタンプ・既読スルー・未読スルーのどれかがランダムで返ってきます。

## 遊び方

1. `koi-kidoku-challenge.html` をブラウザで開く
2. 「トークをはじめる」を押す
3. 表示される3つの候補から、送るメッセージを選ぶ
4. 「話しかける → 話題をふる → 誘う or 告白」の3ステップでエンディングへ

インストールやサーバーは不要です。HTMLファイル1つで動きます。

## 機能

| 機能 | 内容 |
|---|---|
| ランダムな返事 | 即レス／スタンプだけ／既読スルー／未読スルーの4パターン |
| 好感度ゲージ | 即レス +15、スタンプ +5、既読スルー −10、未読スルー −15 |
| 好感度で確率が変化 | 70以上で返事が来やすく、30以下で来にくくなる |
| 告白 | 好感度がそのまま成功率になる（好感度70なら70%） |
| エンディング | 全6種（付き合えた／振られた／ライブデート／週末デート／スタンプだけ／脈なし） |
| エンディング図鑑 | 見たエンディングをブラウザに保存し、タイトル画面で確認できる |

## 演出

- 選んだメッセージが入力欄に1文字ずつ打ち込まれる
- 既読が少し遅れてつき、返事の前に「入力中…」が表示される
- 画面上の時計が物語の時間で進む（既読スルーは3時間後、未読スルーは翌朝へ）
- 好感度の増減が数字で浮かび、下がるとゲージが揺れる
